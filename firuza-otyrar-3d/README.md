# Ежелгі қалалардың 3D моделін жасау

6-сыныпқа арналған ғылыми жобаның интерактивті сайты.

**Автор:** Аяганова Фируза Жандосқызы  
**Жетекшісі:** Бермаганбетова Мейрамгуль Бериковна

[Сайтты ашу](https://kashonee.github.io/firuza-otyrar-3d/) · [Жобаны қорғау](https://kashonee.github.io/firuza-otyrar-3d/#/defense)

Мүмкіндіктері: Отырар негізіндегі 3D оқу моделі, қала бөліктерінің белгілері, үлкейтілетін галерея, масштаб калькуляторы, A/B жоспарларын салыстыру, бес қадамнан тұратын қорғау режимі және білімді тексеру.

Қабырға ұзындықтары: 380, 145, 400, 380 және 350 м. Периметрі: 1655 м. Негізгі масштаб: 1:1000. Бұрыштар, үйлердің орны және биіктіктері шартты; бұл тарихи қаланың дәл көшірмесі емес.

`index.html` — стильдері, JavaScript коды, суреттері және жүктелетін жоба құжаты енгізілген дайын сайт. Қосымша сервер қажет емес. Жариялау осы репозиторийдің GitHub Pages баптауы арқылы орындалады.
