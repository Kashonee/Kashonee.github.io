# TamashaLike

Қазақ тіліндегі 5–8 сынып оқушыларының алгоритмдік ойлауын дамытуға арналған платформа.

## Открыть платформу

https://kashonee.github.io/ai-lab/

## Возможности

- Шесть миссий с роботом: последовательность, декомпозиция, циклы, условия, отладка и оптимизация.
- Конструктор команд, пошаговое выполнение и поиск первого ошибочного блока.
- Отдельные варианты A/B диагностики с историей попыток, прогноз и сравнение с фактическими шагами.
- Черновики по миссиям: сохранение прогноза, паузы и объяснения после переходов и перезагрузки.
- Отмена очистки алгоритма, компактная лаборатория и закреплённые элементы запуска на телефоне.
- Локальный прогресс и выгрузка отчёта CSV.
- Раздел учителя, сценарий урока на 45 минут и режим демонстрации.
- Рубрика учителя по четырём критериям (0–8), запись влияния AI-подсказки и пустой шаблон наблюдения CSV.
- Обновлённый адаптивный дизайн с локальными шрифтами Noto Sans.

AI-анализ открывается отдельно в ChatGPT с подготовленным запросом о текущей миссии и алгоритме. Подсказки внутри платформы заранее подготовлены. Прогресс хранится в браузере на текущем домене; общей базы учеников нет. Работа на общем устройстве требует отдельных браузерных профилей. Прежние результаты сохраняются; старые диагностические записи помечаются A-v1. A/B варианты не являются стандартизованным исследованием эффективности.

## Локальный запуск

Из этой папки: `python3 -m http.server 8080`. Затем откройте http://localhost:8080/.

Сборка и установка зависимостей не требуются. Все пути относительные, поэтому платформа работает в подпапке GitHub Pages.

## Проверки

Из этой папки: `npm test` (стандартный тестовый раннер Node.js, без зависимостей).

## Файлы

`app.js` — интерфейс; `workspace.js` — совместимое восстановление черновиков и рубрика; `engine.js` — интерпретатор и миссии; `style.css` — базовые компоненты; `design.css` — обновлённая визуальная система. Лицензия шрифтов находится в `assets/FONT-LICENSE.txt`.
