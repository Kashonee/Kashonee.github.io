Groq арқылы ИИ тексеруін қосу

Жауап пішімін түзету · v3. «ИИ жауабы тексеруден өтпеді» қатесіне арналған өңдеу жаңартылды. Кілттер мен кестелер қосылған болса, 3-қадамдағы функция кодын жаңартыңыз, содан кейін сайт бетін жаңартыңыз. ИИ үзінді нөмірін таңдайды, ал түпнұсқа мәтінді сервер өзі қосады.

Groq тіркелгісі дайын болса, төмендегі үш қадамды орындаңыз. Free Plan тарифінде тексеру сервис лимиттері аясында тегін. Нақты лимиттер тіркелгіге және модельге байланысты.

OpenAI-дан ауысу: бұрын құрылған check-writing функциясын жаңартамыз. Оқушының нәтижелері мен мұғалім бағалары сақталады. ai-review.sql бұрын орындалған болса, оны қайта іске қосу қажет емес.

1. Groq API кілтін жасаңыз

Groq → API Keys бетін ашып, Create API Key батырмасын басыңыз. Groq ішіндегі кілттің белгісін QAISAR OLYMP деп атауға болады. Жасалған толық кілтті көшіріңіз.

Free Plan тарифінде қалыңыз. Ақылы Developer тарифіне ауысу бұл нұсқаулық үшін қажет емес. Data Controls бөлімінде оқушы мәтіндері үшін Zero Data Retention мүмкіндігін қосуға болады.

Құпия кілтті чатқа, GitHub-қа немесе сайттың ашық конфигурациясына енгізбеңіз. Оны тек келесі қадамдағы сервер баптауына сақтаңыз.

2. Supabase Secrets ішіне екі мән сақтаңыз

Өз Supabase жобаңызды ашып, Edge Functions → Secrets бөліміне өтіңіз. Біріншісін толтырып, Add another арқылы екіншісін қосыңыз.

NameValue
GROQ_API_KEYGroq берген толық құпия API кілті
AI_PROVIDERgroq

Save батырмасын басыңыз. Supabase ішіндегі атау дәл GROQ_API_KEY болуы керек. QAISAR OLYMP — Groq-тағы еркін белгі; ол сервер айнымалысының атауы емес. DIGEST бағанындағы хэш толық API кілтінің орнына жүрмейді.

Бұрынғы OPENAI_API_KEY сақталып тұрса да, AI_PROVIDER=groq кезінде қолданылмайды. Groq қолжетімсіз болса, функция OpenAI-ға автоматты ауыспайды.

3. check-writing функциясының кодын жаңартыңыз

Edge Functions → Functions → check-writing жолымен өтіп, функцияның код редакторын ашыңыз. index.ts ішіндегі ескі кодты төмендегі жаңартылған кодпен толық алмастырыңыз. Өзгерісті Deploy / Deploy updates арқылы жариялаңыз.

Функция әлі жасалмаған болса: Deploy a new function → Via Editor арқылы дәл check-writing атауымен жасаңыз.

Жаңа npm пакеттері қажет емес. JWT тексеруін қосулы қалдырыңыз. Сервер әр сұрауда пайдаланушыны және оқушы–мұғалім байланысын тексереді.

Сайттан тексеріңіз

  1. Сайт бетін жаңартып, жеке кабинетке кіріңіз.
  2. «Жазылым шеберханасы» ішінен кемінде 30 сөзі бар жұмысты ашыңыз.
  3. «Қызметті қайта тексеру» батырмасын басыңыз. Тексеру түсіндірмесінде Groq қызметіне жіберіледі деп көрсетілуі керек.
  4. «Серверде сақталды» күйін күтіп, «Мәтінді ИИ арқылы тексеру» батырмасын басыңыз.
  5. Мұғалім ретінде сол оқушының жұмысын ашып, сақталған талдауды қараңыз.

W1–W2 диагностикасы төрт блок жіберілген соң, M1–M3 нұсқалары нұсқа жіберілген соң ашылады. P1–P6 мәтіндерін жазу барысында тексеруге болады.

Талдау және лимиттер

ИИ мазмұн, құрылым және тіл бойынша 0–2 ұпайдан алдын ала баға береді. Бұл ресми олимпиада шкаласы емес; мұғалім бағасы бөлек сақталады. Мәтін өзгерсе, ескі талдау белгіленеді. Алғашқы бірнеше жұмыстың бағасын мұғалім өз бағалауымен салыстырғаны дұрыс.

Платформа шегі: бір оқушыға 24 сағатта 6 жаңа талпыныс, бүкіл жобаға 50 талпыныс. Сәтсіз талпыныстар да есептеледі; бұл шектер қызметті ауыстырғанда жойылмайды. Groq-тың өз сұрау және токен лимиттері қосымша қолданылады. Қайталанған сұрауларға бір мәтін, модель және талдау нұсқасының сақталған нәтижесі қайта беріледі.

Әдепкі модель: openai/gpt-oss-120b, оны Groq іске қосады. Бұл модель атауы OpenAI API-ға сұрау жіберілетінін білдірмейді. Қажет болса, GROQ_MODEL=openai/gpt-oss-20b сервер айнымалысын қолдануға болады. Модель ауысқанда сақталған талдаулар жойылмайды.

Қызметке тапсырма мен мәтін жіберіледі; логин, пароль және басқа оқушылардың жазбалары қосылмайды. Деректі сақтау тәртібі Groq баптауларына байланысты. ИИ нәтижесі Supabase ішінде сақталады. Groq деректер туралы түсіндірмесі.

Қосылмаса

Жаңа функция жауап қабылданбаған жағдайда қауіпсіз анықтама кодын береді: AI01 — үзінді нөмірі; AI02 — баға; AI03 — бөлімдер; AI04 — мәтін өрісі; AI05 — тақырып коды; AI06 — JSON; AI07 — сервис пішімі; AI08 — жауап мазмұны; AI09 — көлем; AI10 — объект құрылымы. Қайталанса, осы кодты хабарлаңыз. Құпия кілт пен оқушы мәтіні қате хабарламасына қосылмайды.

  • Groq кілті табылмады: Secrets ішіндегі атауды дәл GROQ_API_KEY деп сақтаңыз.
  • Кілт қабылданбады: Groq берген толық кілтті қолданыңыз; DIGEST хэшін немесе OpenAI кілтін көшірмеңіз.
  • Уақытша сұрау шегі: біраз уақыт күтіңіз; қайталанса, Groq лимиттерін тексеріңіз.
  • Әлі OpenAI деп көрсетілсе: AI_PROVIDER=groq мәнін сақтап, үшінші қадамдағы жаңа кодты жариялаңыз, сайттағы қызметті қайта тексеріңіз.
  • Сақтау қызметі дайын емес: осы беттегі SQL кодын орындаңыз.

Бұл бет пен кодтың жариялануы сіздің Supabase функцияңыз жаңартылды дегенді білдірмейді. Нақты кілтпен қызметті қосқаннан кейін бір жұмысты тексеріп көріңіз.
