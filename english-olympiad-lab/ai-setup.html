ИИ тексеруін қосу

Интерфейс пен сервер коды дайын. Тексерудің іске қосылуы үшін өз Supabase жобаңызда төмендегі үш қадамды орындаңыз. Бұрынғы оқушы жауаптары мен мұғалім бағалары өзгермейді.

Бір рет бапталады. Әр эссе үшін жаңа SQL сұрауын немесе жаңа функция жасаудың қажеті жоқ. Жұмыс істеп тұрған check-writing функциясы барлық 11 жазылым тапсырмасын өңдейді.

1. Нәтижелер кестесін қосыңыз

Қолданыстағы Supabase жобаңызды ашыңыз. SQL Editor бөлімінде төмендегі кодты орындаңыз. Бар сұрау терезесін қолдануға да болады. Негізгі schema.sql бұрын орындалған болуы керек.

2. OpenAI кілтін серверге қосыңыз

OpenAI API тіркелгісінде API кілтін жасаңыз. API жобасының төлемі мен шығын шегін тексеріңіз. Supabase ішіндегі Edge Functions → Secrets бөлімінде мына мәнді сақтаңыз:

OPENAI_API_KEY — өзіңіздің құпия API кілтіңіз.

Кілтті чатқа, GitHub-қа немесе сайттағы ашық конфигурацияға енгізбеңіз. Осы бетте кілт енгізетін өріс жоқ: оны тікелей Supabase ішінде сақтайсыз.

Әдепкі модель: gpt-4.1-mini. Қажет болса, OPENAI_MODEL сервер айнымалысын өзгертуге болады; модель Responses API және JSON Schema Structured Outputs пішімін қолдауы керек. Үлгі не бағалау ережесі өзгерсе, функциядағы PROMPT_VERSION нұсқасын да жаңартыңыз.

3. Бір сервер функциясын жариялаңыз

Edge Functions → Deploy a new function → Via Editor бөлімін ашыңыз. Атауын дәл check-writing деп қойыңыз. Редактордағы index.ts мазмұнын төмендегі кодпен толық ауыстырып, Deploy батырмасын басыңыз.

Қосымша npm пакеттері қажет емес. JWT тексеруі қосулы болсын. Функция пайдаланушыны Supabase Auth арқылы қайта тексеріп, тек өз жұмысына немесе өзіне бекітілген оқушының жұмысына рұқсат береді. Supabase сервер кілттері ортадан оқылады; оларды қолмен браузерге қоспаңыз.

Сайттан тексеріңіз

  1. Оқушы ретінде кіріп, «Жазылым шеберханасы» ішінен тапсырма ашыңыз.
  2. Кемінде 30 сөз жазыңыз. «Серверде сақталды» күйін күтіңіз.
  3. «Қызметті қайта тексеру», содан кейін «Мәтінді ИИ арқылы тексеру» батырмасын басыңыз.
  4. Мұғалім ретінде оқушының нәтижесін ашыңыз: сол мәтінге арналған ИИ талдауы бөлек блокта көрінеді.

Диагностикалық W1–W2 тек төрт блок жіберілгеннен кейін, M1–M3 нұсқалары тек нұсқа жіберілгеннен кейін тексеріледі. P1–P6 шеберхана мәтіндерін жазу барысында тексеруге болады.

Нені ескеру керек?

ИИ алдын ала 0–2 ұпайдан мазмұн, құрылым және тілге баға береді; бұл ресми олимпиада шкаласы емес. Мұғалім бағасы автоматты өзгермейді. Мәтін өзгерсе, бұрынғы талдау ескі нұсқаға тиесілі деп көрсетіледі.

Бір оқушыға 24 сағатта 6 жаңа сұрау, бүкіл жобаға 50 сұрау шегі қойылған. Мұғалім мен оқушы сұраулары бір оқушының шегіне бірге кіреді. Сәтсіз талпыныстар да шекке есептеледі. Бірдей мәтіннің сақталған талдауы қайта қолданылып, жаңа API сұрауы жіберілмейді.

OpenAI қызметіне тапсырма мен мәтін жіберіледі; логин, пароль, басқа оқушылардың деректері қоса жіберілмейді. Жауаптарға store:false орнатылған; бұл OpenAI жағында ешқандай техникалық дерек сақталмайды деген кепілдік емес. ИИ нәтижесі Supabase ішінде бөлек сақталады.

Қосылмаса

  • «ИИ тексеруі әлі қосылмаған»: функция атауын және OPENAI_API_KEY мәнін тексеріңіз.
  • «Сақтау қызметі дайын емес»: бірінші қадамдағы SQL сұрауын орындаңыз.
  • «ИИ қызметі жауап бермеді»: API кілті, модельге рұқсат және OpenAI жобасының төлемін тексеріңіз.
  • «Сервердегі мәтін өзгерген»: соңғы мәтіннің сақталуын күтіп, нәтижелерді жаңартыңыз.

Осы нұсқаулықтың жариялануы функцияның сіздің жобаңызда іске қосылғанын білдірмейді. Қосылғаннан кейін нақты екі оқушы және мұғалім тіркелгілерімен қолжетімділікті тексеріңіз.
