# English Olympiad Lab

Открытая учебная платформа подготовки к олимпиаде по английскому языку. Интерфейс и объяснения — на казахском, задания — на английском.

Сайт: https://kashonee.github.io/english-olympiad-lab/

Включены 88 диагностических заданий, два диагностических письменных задания, 21 мини-урок, 63 тренировочных упражнения, 40 словарных карточек и шесть новых заданий Writing.

Эта публичная версия не содержит ФИО, класса, фактических ответов, оценок или результатов конкретного ученика. Данные выполнения хранятся в браузере пользователя. Файл JSON позволяет переносить собственный прогресс и получать ручные оценки учителя. Автоматической передачи результатов на сервер нет.

Все файлы приложения находятся в этой папке. Для публикации достаточно статического хостинга; здесь используется настроенный GitHub Pages из ветки main. Отдельный сервер и установка пакетов не требуются.

Writing оценивается вручную. Отдельные защищённые кабинеты и серверная синхронизация не реализованы. Это учебный тренажёр, а не защищённая экзаменационная система.

Содержимое тестовых вопросов является статическим учебным материалом. Ключи описывают правильные ответы на упражнения, а не ответы какого-либо ученика.
