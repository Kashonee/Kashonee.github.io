Подключение кабинетов

Код входа и учительского кабинета подготовлен. Сервер ещё не подключён: аккаунты и автоматическая передача результатов пока не работают.

1. Создайте проект Supabase

Откройте Supabase Dashboard и создайте проект в своём аккаунте. Пароль базы данных сохраните у себя; отправлять его в чат не нужно.

2. Создайте таблицы и правила доступа

В проекте откройте SQL Editor → New query. Вставьте содержимое файла ниже и нажмите Run. Скрипт включает ограничения: ученик видит своё, учитель — закреплённых учеников.

3. Создайте два аккаунта

Authentication → Users → Add user → Create new user. Создайте пользователей с разными паролями не короче 12 символов. Включите подтверждение email (Auto Confirm User).

Учительteacher@olympiad-lab.invalidteacher
Ученикstudent@olympiad-lab.invalidstudent

Это технические имена аккаунтов. Письма на них не доставляются. Пароли задайте самостоятельно и передайте ученику его пароль лично. Для восстановления пароля используйте Dashboard. Если меняете логины, измените их также в следующем скрипте.

Открытая регистрация на сайте отсутствует. В Supabase отключите Authentication → Sign In / Providers → Allow new users to sign up. Создание через Dashboard остаётся доступным.

В SQL Editor выполните второй скрипт. Он назначит первому аккаунту роль учителя и закрепит за ним второй аккаунт. Роль нельзя изменить через форму ученика.

Проверьте доступ

После назначения ролей выполните в SQL Editor verify-access.sql. Скрипт проверяет запись ученика, отказ в самостоятельном выставлении оценок, доступ учителя и конфликт версий. Пробные записи откатываются.

5. Передайте два публичных значения для подключения

В диалоге Connect проекта найдите Project URL и Publishable key, начинающийся с sb_publishable_. Их можно передать для настройки сайта. Пароли, database password и Secret key передавать не нужно.

Эти значения будут записаны в cloud-config.js. Пока там пустые строки, сайт честно работает только как локальный тренажёр.

6. Проверьте два входа

После активации войдите как student в приватной вкладке, ответьте на вопрос и дождитесь сообщения «Серверде сақталды». В обычной вкладке войдите как teacher, нажмите «Нәтижелерді жаңарту» и откройте ученика. Проверьте также доступ с другого устройства.

Ответы проверяются по заданиям. Письменную работу оценивает учитель; оценка привязана к конкретному тексту. Изменённое эссе требует новой проверки.

Старый локальный прогресс можно выгрузить JSON-файлом до активации и импортировать после входа в аккаунт ученика. Не импортируйте его в учительский кабинет.
