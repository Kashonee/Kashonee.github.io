Кабинеттерді қосу

Жүйеге кіру мен мұғалім кабинетінің коды дайын. Сервер әлі қосылмағандықтан, тіркелгілер мен нәтижелерді автоматты жіберу әзірге жұмыс істемейді.

1. Supabase жобасын құрыңыз

Supabase басқару панелін ашып, өз тіркелгіңізде жоба құрыңыз. Дерекқор құпиясөзін өзіңізде сақтаңыз; оны чатқа жіберудің қажеті жоқ.

2. Кестелер мен қолжетімділік ережелерін қосыңыз

Жобада SQL Editor → New query бөлімін ашыңыз. Төмендегі файл мазмұнын енгізіп, Run батырмасын басыңыз. Ережелер бойынша оқушы тек өз деректерін, ал мұғалім өзіне бекітілген оқушылардың деректерін көреді.

3. Екі тіркелгі құрыңыз

Authentication → Users → Add user → Create new user бөлімінде әрқайсысына кемінде 12 таңбалы бөлек құпиясөз беріңіз. Электрондық поштаны автоматты растауды қосыңыз (Auto Confirm User).

Бұлар — тіркелгілердің жүйелік атаулары. Бұл мекенжайларға хат жеткізілмейді. Құпиясөздерді өзіңіз орнатып, оқушының құпиясөзін оған жеке беріңіз. Қалпына келтіру үшін басқару панелін пайдаланыңыз. Логиндерді өзгертсеңіз, келесі скрипттегі атауларды да өзгертіңіз.

Сайтта ашық тіркелу жоқ. Supabase жүйесінде Authentication → Sign In / Providers → Allow new users to sign up параметрін өшіріңіз. Басқару панелі арқылы пайдаланушы құру мүмкіндігі сақталады.

4. Рөлдер мен оқушыға байланысты орнатыңыз

SQL редакторында екінші скриптті орындаңыз. Ол бірінші тіркелгіге мұғалім рөлін беріп, екінші тіркелгіні соған бекітеді. Оқушы өз формасы арқылы рөлін өзгерте алмайды.

Тапсырмалар қызметін қосыңыз

Диагностика, авторлық тапсырмалар және жеке ұсыныстар беру үшін schema.sql скриптінен кейін assignments.sql скриптін орындаңыз.

Қолжетімділікті тексеріңіз

Рөлдерді бергеннен кейін SQL редакторында verify-access.sql скриптін орындаңыз. Ол оқушының деректерді сақтауын, өзіне баға қоюына тыйымды, мұғалімнің қолжетімділігін және нұсқалар қақтығысын тексереді. Сынақ жазбалары сақталмайды. Тапсырмалар кестелерінің ережелерін де бөлек тексеріңіз: оқушы басқа оқушының тапсырмасын көрмеуге, мұғалім ғана тапсырма беруге тиіс.

5. Қосылуға арналған екі ашық мәнді беріңіз

Жобаның Connect терезесінен Project URL және sb_publishable_ деп басталатын Publishable key мәндерін табыңыз. Оларды сайтты баптау үшін беруге болады. Құпиясөздерді, дерекқор құпиясөзін және Secret key мәнін жібермеңіз.

Бұл мәндер cloud-config.js файлына енгізіледі. Ондағы жолдар бос тұрғанда, сайт тек осы браузерде сақталатын жаттығу құралы ретінде жұмыс істейді.

6. Екі тіркелгімен кіруді тексеріңіз

Жүйе қосылған соң, жеке қойындыда student ретінде кіріңіз. Бір сұраққа жауап беріп, «Серверде сақталды» хабарламасын күтіңіз. Қалыпты қойындыда teacher ретінде кіріп, «Нәтижелерді жаңарту» батырмасын басыңыз да, оқушыны ашыңыз. Басқа құрылғыдан да тексеріңіз.

Жауаптар тапсырмалар бойынша тексеріледі. Жазба жұмысты мұғалім бағалайды; баға мәтіннің нақты нұсқасына байланады. Эссе өзгертілсе, оны қайта тексеру қажет.

Бұрынғы жергілікті ілгерілеуді жүйе қосылғанға дейін JSON файлына жүктеп алуға болады. Оны кейін оқушы тіркелгісіне кірген соң ашыңыз. Мұғалім кабинетіне импорттамаңыз.
